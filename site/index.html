Your network is a flock

Right now, you can't see it.

Most of what's on your network is harmless. Some of it is tracking you. A little of it, one day, will be an attacker, or a device that has gone bad. The tools that can show you this are either closed hardware you rent forever, or a pile of dashboards that don't talk to each other.

Shepherd runs on a NAS, a mini PC, a Mac, a Windows box — or a Raspberry Pi — inside your network. No new router. It learns who your devices are, what they talk to, and notices the black sheep: the device that doesn't belong.

What's shipped

Real, tested, running on a real network.

Shepherd is built in public. Everything below is live today — not a roadmap slide. See CHANGELOG.md for the full, dated history.

DNS FILTER

A catalog of 95 lists, apps & categories

Block Instagram, Discord, YouTube, Steam, Social, Gaming, Adult, Gambling and more — plus custom lists from a URL or pasted text. Scope any block (or allow) to the whole network, a group of devices, or just one device.

POLICY

Allowlist mode & scheduled access

Flip any scope from block-by-default to allow-by-default. Any rule can carry a day-of-week / time-of-day schedule, so a block or allow only applies inside the window you set.

DEVICES

Devices with real names

Learned passively from DNS, the neighbor table, mDNS and reverse DNS — with vendors, automatic classification (phone, camera, TV, speaker…), groups, search and bulk edit. New devices land in Quarantine automatically until you look at them.

WANDER

Wandering mode

Stop filtering one device entirely while still watching and logging everything it does, with an optional auto-reverting timer. For the one laptop that needs to see the raw internet, temporarily.

HUD

The globe HUD

Live traffic arcs wrap a 3D globe from home to every destination, weighted so heavy lanes glow brighter. Click an arc, a device or a destination to block or allow it, live, with undo. Scrub a timeline to replay last Tuesday at 3 a.m.

HISTORY

Encrypted, searchable history

Opt-in query history sealed with AES-256-GCM in immutable, individually keyed segments, unlocked with a passphrase or key file. In-memory only remains the default.

ALARMS

An alarm engine that actually delivers

Severities, dedupe, storm control, mute rules and quiet hours, batch actions, and a digest for low-severity alarms — delivered over ntfy today. Web Push is designed but waits on the portal getting HTTPS.

PORTS

Port & exposure scanning

Scheduled, gentle TCP connect scans of every known device's common ports, with history and flags for a newly-opened port or a specifically risky one — Telnet, RDP, SMB, VNC, an unauthenticated Docker API and more.

VULNSCAN

Vulnerability scanning, not just port numbers

Not "port 23 is open" but "Telnet is open," or "this OpenSSH build is missing a named fix." A curated signature table — confirmed with a real, gentle protocol probe — covers outdated SSH/OpenSSH, unencrypted or anonymous FTP, the vsftpd 2.3.4 backdoor, stale Apache/nginx/lighttpd, an open Docker API, and SMBv1.

GEO-BLOCK

Geo-IP country blocking

Firewalla-style, per-scope lists of ISO country codes whose DNS answers get blocked — network, group, or one device at a time, reusing the same GeoIP database that powers the globe.

LOCKING

Portal locking

The portal shows synthetic demo data until it's unlocked. A PIN, bound to up to 20 trusted browsers and hashed with Argon2id, plus idle auto-lock. Passkeys are designed for, waiting on the portal's own HTTPS.

UPSTREAMS

Self-healing upstreams

Plain DNS, DNS-over-TLS and DNS-over-HTTPS, with continuous health probing, automatic failover and fastest-healthy-first ordering — born from a real outage where an encrypted upstream stalled an entire network.

Also shipped: passive ARP monitoring (learns real MAC addresses, flags spoofing signatures) · Tailscale integration for private remote access · Apple iCloud Private Relay blocking, on by default · router import from eero or CSV, with a dry-run preview · accountability-partner email alerts, a self-hosted alternative to Covenant Eyes · IPv6, Thread and Matter protected by rules in the code, not by luck.

What's coming

Built in public — including what isn't done yet.

Shepherd ships in tested increments, deployed to a real network as they land. Here's what's honestly still ahead. See docs/ROADMAP.md for the full, numbered list.

Reverse proxy & HTTPS planned

Wildcard certificates on Cloudflare DNS, private service names, Cloudflare Tunnel — and the portal's own first real HTTPS, which several other features (Web Push, passkeys) are waiting on.

Passkeys planned

Designed as part of portal locking already — WebAuthn needs HTTPS, so this follows the reverse proxy directly.

Network health history next up

Ping/latency, jitter, packet loss, bufferbloat, reachability and traceroute, run on an interval and kept over months so reliability trends are visible, not just this instant.

Inbound protection planned

Logging, rate limits and blocking at the proxy and tunnel, exposure alarms, host-level inbound tracking.

Mesh planned

Run more than one Shepherd; a synced dataset of rules, devices, alarms and history, with a standby that takes over in seconds.

Self-maintenance planned

Signed self-update with rollback, retention budgets, digests — so an install looks after itself the way the blocklists and upstreams already do.

Threat feeds & a local AI planned

A model that learns what normal looks like for each device and explains what's strange, in plain English, without a byte leaving your house.

Packaging & installers planned

A real setup wizard and release channels. Today it's a binary and a config file — see running it below.

⚠ About "Watch mode" (ARP interception)

You may see Watch mode mentioned elsewhere — one-sided ARP steering that would let Shepherd see and control a device's traffic even past its DNS. It is not live today. The engine is real and tested, but it only runs by hand, in short trials, through a standalone CLI — nothing in the normal app or portal wires it in yet. A live trial found a real, still-unresolved throughput cost on the steered device (roughly 1.1 Gbps down to ~300 Mbps), and that gates it from going further.

Everything above this box — DNS filtering, devices, the globe, alarms, scanning — has zero network cost and runs today. Watch mode would close one specific gap (a device that deliberately avoids your DNS resolver), not replace any of it. Read the honest, row-by-row comparison in docs/WATCH-MODE-COMPARISON.md.

Hardware you already own

One static binary. No Docker, no database server.

Shepherd cross-compiles to Linux, macOS and Windows with no CGO. Run it on a NAS, a mini PC, an old laptop — or a Raspberry Pi 3 or newer.

  • ● DNS-only protection costs the network nothing — it never adds a hop to anyone's traffic, Pi included.
  • ● Answering DNS against an in-memory blocklist, passive device learning, the catalog/policy engine and the portal itself are all light enough for a Pi 3 or 4 to handle a typical home's query volume without strain.
  • ● Watch mode's software relay is the one piece that isn't free — treat it as an occasional, short trial on a Pi, not something you run constantly, until its throughput cost is resolved.
  • ● No formal installer yet — this is a binary-and-a-config-file setup today. See docs/RASPBERRY-PI.md for the full systemd walkthrough.
# clone and build git clone https://github.com/blaineam/shepherd && cd shepherd make build # configure — set dns.listen and portal.listen cp shepherd.example.toml shepherd.toml # run it beside your current resolver first bin/shepherd -config shepherd.toml # cross-compile for a Raspberry Pi (arm64) GOOS=linux GOARCH=arm64 CGO_ENABLED=0 \ go build -trimpath -o shepherd-arm64 ./cmd/shepherd

Principles

Open and honest, by construction.

Private by design

No telemetry, no accounts. The only outbound connections are your DNS upstreams and blocklist downloads.

Never breaks your smart home

IPv6, Thread, Matter and mDNS are protected by rules in the code, not by luck.

Free and keyless

No paid APIs. Every data source works without an account.

Self-maintaining

Lists, upstreams and storage look after themselves, with guardrails and rollback.

Protected by default

Set it up once and every device is covered. You opt out, never opt in.

Open source, AGPL-3.0-or-later

See your network. Keep it to yourself.

If you run a modified Shepherd as a service, you share your changes — that's the whole deal.
